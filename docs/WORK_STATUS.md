- **Correção:** todos os `throws_ok` passaram para a forma explícita de 4 argumentos — `throws_ok(sql, '42501', 'permission denied for table studies', descrição)` — eliminando a ambiguidade. Nenhuma policy nem GRANT foi alterado.
- **GRANT vs. RLS (documentado, DEC-025):** a mensagem observada ("permission denied for table studies") é a mensagem padrão do Postgres para ausência de GRANT — diferente de "new row violates row-level security policy for table ...", que seria a mensagem de uma policy de escrita rejeitando a linha.
